# SEO — not doing (operator ruling 26.10)

No content layer: no how-to/FAQ copy blocks, no generated landing text,
no sitemap-bait pages. Tool pages ship tool + technical meta (title,
description, canonical, hreflang, sitemap) and nothing more.

The YouTube page's existing FAQ block is a grandfathered pre-ruling artifact
(single exception, see AGENTS.md) — do not replicate it.

Host is <user>.github.io/<repo> by choice (no domain registration); Google
demotes .github.io in search; that is accepted. If a domain is ever bought,
revisit this doc — it stays 'not doing' until the operator says otherwise.
